## P1 —— 工具链补全（按依赖排序，对应《恢复与退役-设计与排期-2026-09-29》的批次）

2. **`rdsh doctor`**（B2）：一键只读体检 —— 版本/数据对应关系、软链完整性（**为 0 个检查对象要报错，不能"零检查却报全绿"**）、插件与权威副本一致性、启动日志报错扫描、磁盘/内存余量、账本与磁盘是否一致。
   **它是 restore / retire / migrate 共用的验证引擎**，必须先做 —— 否则每个新命令会长一套半吊子自检。
3. **`rdsh du`**（B3）：衍生物账本 —— 备份快照 / 回收目录 / 调试沙箱 / 启动日志 / fetch 临时 / 历史 bundle 的体积、份数、最老日期；**默认只列不删**，`--purge` 才真删（年龄守卫 + 打印释放量）。配套：`RDSH_TRASH` 默认改到**同文件系统**并给回收项建索引（现在散在 `/tmp/rdsh-trash-*`、没有索引，且 `/tmp` 可能是 tmpfs）。
4. **`rdsh restore`**（B4）：`--list` / `--from <目录|远端|本地克隆>` / `--type <类>` / `--file <路径>` / `--diff` / `--merge` / `--with-creds`。三类来源要分开；记忆三库是 append-only 语义，默认 `--merge` 而非覆盖；恢复后自动收尾（重链 → `plugin-sync --status` → 断链计数 + `memory_check`，走 doctor）。**会话数据只从本地指定目录恢复，永不联网**。
5. **`rdsh backup --snapshot`**：数据 home 的**增量硬链接快照**（现在 `rdsh backup` 是 `cp -a` 全量，GB 级天天跑会爆盘）+ `--verify` + `--keep N` 保留策略。
6. **`rdsh retire`**（B6）：退役 —— 五类足迹（检出 / 数据 home / home 内插件软链 / 指向它的全局软链 / 日志+注册表+`.map`+账本+systemd 单元）逐项移走并留痕；先停实例、是回退基线或最后一版可用版本则拒绝（`--force` 放行基线并写明后果）；移动后扫断链。
7. **`rdsh uninstall <版本>`**（语义修正）—— 它是 `install` 的**反面**：只移走 `node_modules` 与 `.installed`（回到未安装态），**检出与数据都不动**。退役是 `rdsh retire`，两者别混（旧条目把"删检出/数据"错挂在 uninstall 名下）。
8. **同版本共存编号**（B7）：`fetch --dir` / `add` / **`restore`** 都能造出同版本号的第二份检出，而它们现在会映射到**同一个数据 home**（互相写 `workspace.json`/`settings`）。做法：`-2` 后缀全链一致（目录名/数据目录/显示名/账本键），用 `.map` 的 `dir|` 行分数据 home；**不压缩重排次号**（旧引用会静默指向别的对象），删了留墓碑。
9. **`settings.yaml` 迁移携带**（B8）—— **不纳入稳定根**（各版本 schema 不通用，实为坑）：保持每版本一份真文件，`migrate.sh` 迁移时**显式携带**（schema 感知：新版本认得的键写入，不认得的保留并告警），并在账本里登记。
10. **`rdsh selfupdate`** + 仓库根 **`bootstrap.sh`**（B10）：前者是"有 rdsh 时更新工具自身"，后者是"**没有 rdsh 时**的入口"（clone → chmod → `~/.local/bin/rdsh` 软链 → 探测 BASE）。注意**不能 `git clone` 覆盖 `$BASE/dsh`**——那里同时住着 6G+ 检出；`bootstrap.sh --into` 只搬 `publish.sh` 的白名单脚本集。
11. **`rdsh plugins`**：包装 `plugin-sync.sh`，让插件维护也走单入口。

## 已知风险（未解）

- **无构建记录**：无法判断某个 `lib/` 是哪次构建的产物（源码版本 / 构建时间 / 校验和）。
- **mtime 只是近似方向判断**：`cp -a` 保留时间、手改刷新时间，都可能误导同步方向。
- **网络依赖**：GitHub 不畅时 `fetch` 会失败（已做缓存与 `git ls-remote` 回退）。
- **检查器可能「零检查却报全绿」**：任何新增的自检工具都要打印「检查了几个对象」，并在为 0 时报错。
