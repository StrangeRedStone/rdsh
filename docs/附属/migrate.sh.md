# migrate.sh —— 跨版本迁移（附属）

> 附属脚本；`rdsh migrate` 转发到它。**动数据**，按安全底线先查环境 → 预测后果 → 备份并给还原命令。

- **依赖**：`bash`、`rsync`、`git`；目标版本检出需已装依赖（`node_modules` + `.installed`）。
- **能力**：把一个版本的运行环境搬到另一个版本 —— 备份 → 建软链 → 搬数据 → 装插件 → 探针 → 记回退基线。
- **提供的定义**："什么算迁移完成"（探针通过 + 回退基线在案）。
- **提供的证据**：迁移日志 + `回退基线.md` + `compat_check` 报告（`--live` 才是实测门）。
- **工作方式**：**不搬**稳定根共享资产（`$BASE/.dsh-suite/shared/`），各版本 home 内只建软链。
- **变量**：`DSH_BACKUP_ROOT`、`DSH_SHARED_HOME`（现已由 BASE 推导）。
- **示例**：`bash migrate.sh <源> <目标>`。
- **边界**：稳定根共享资产**刻意不搬**（那正是它避免"同一份资产多份副本"的设计）。
