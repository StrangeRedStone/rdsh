# 外部能力：让 rdsh 支持插件

**一句话**：把一个**可执行文件**放进 `plugins.d/`，它就成为 rdsh 的一条命令；同时自动出现在 `rdsh bridge --spec` 里——于是 dsh 里的 agent 也能看到并调用它。**不需要改 rdsh 的任何代码。**

> 说清动机：rdsh 原来要加一条命令，得改主脚本的派发、帮助、契约表、冒烟、发布清单（约 10 处）。
> 有了这个机制，**加能力的成本 = 加一个文件**；rdsh 自己也因此能长大，而别人也能给它写能力。

---

## 三步

1. **写一个可执行文件**（shell / Python / 任何语言都行）；
2. **让它支持 `--manifest`**：打印自己的接口版本与能力清单（见下）；
3. **放进外部能力目录**：默认是 `<rdsh 部署目录>/plugins.d/`（可用环境变量 `RDSH_PLUGINS_DIR` 改）。

之后：

```bash
rdsh selfcheck          # 校验（接口版本 / 清单格式 / 撞名）
rdsh bridge --spec      # 你会在清单里看到它
rdsh <你的子命令> …      # 直接调用
```

---

## `--manifest` 输出的格式

```
iface=1
<id>|<子命令>|<参数>|<风险>|<默认参数>|<简介>
```

- `iface=`（可选，默认 1）：**接口版本**。与 rdsh 期望的不一致时，rdsh **拒绝加载**并说明原因（不会静默半死不活）。
- 能力行：**正好 6 个字段**，用 `|` 分隔——**字段里不能出现 `|`**（会错位，rdsh 会报错）。
  - `id`：能力标识，建议 `x-` 前缀（见下"命名"）。
  - `子命令`：`rdsh <子命令>` 调它。可以带子子命令，如 `archive`（之后由你的脚本自己解析 `ls`/`collect`…）。
  - `参数`：给人看的用法说明（**不参与校验**，真正的校验在你这边）。
  - `风险`：`read`（只读）/ `write`（会改盘）/ `destructive`（破坏性）。
    - 这个字段**会被 dsh 侧当真**：destructive 的能力，工具侧会要求显式确认、并按"默认参数"补安全默认。
  - `默认参数`：调用时替你补上的参数（例如 `--dry-run`）。**注意：安全默认要靠你自己的脚本也兑现**（"声明的默认"与"脚本的实际默认"必须一致，否则直接调用就不安全——这是 0.9.2 之前的一个真缺陷）。
  - `简介`：一句话，会显示在 dsh 的工具列表里。
- 可以打印多行能力（一个文件提供多条命令）。

## 你会收到的环境变量（**不用自己再找路径**）

rdsh 调用你之前会把**已经解析好的**环境放进环境变量，所以你的脚本里**不应再重复解析根目录**（这是老脚本里被复制了 7 遍的东西）：

| 变量 | 含义 |
|---|---|
| `RDSH_CALLER` | 谁在调你：`cli`（人敲的）/ 将来可能有 `dsh` 等 |
| `RDSH_PLUGIN_ID` | 你被识别出的能力 id（便于打日志） |
| `RDSH_IFACE_VERSION` | rdsh 期望的接口版本（与你的 `iface=` 对比过才调你） |
| `RDSH_SPEC_VERSION` | 门面契约版本 |
| `RDSH_BASE` | 套件基目录（= `rdsh base`） |
| `RDSH_MANAGE_ROOT` | rdsh 与各检出所在目录 |
| `RDSH_DATA_ROOT` / `RDSH_BACKUP_ROOT` / `RDSH_SHARED_ROOT` / `RDSH_STATE_ROOT` | 数据 / 备份 / 共享 / 状态账本根 |
| `RDSH_JOURNAL` | 事件流水文件（**要记账就追加到这里**，别自己另造格式） |
| `RDSH_PATCHES_ROOT` / `RDSH_PLUGIN_ROOT` / `RDSH_LOG_DIR` | 补丁仓 / 插件权威副本 / 日志目录 |

## 命名与冲突

- 外部能力用 **`x-` 前缀**（例：`x-session-archive`）。**id 撞名会让 rdsh 直接报错**，不会静默覆盖。
- 子命令名若与 rdsh 内置命令相同，**内置优先**（你的不会被调用）——请换名字。

---

## 出错时的行为（刻意"不静默"）

| 情况 | rdsh 的反应 |
|---|---|
| 文件不可执行 / `--manifest` 读不到 / 没有输出 | **报错并停下**（"没输出"不会被当成"没有能力"） |
| 能力行不是 6 字段 | **报错**，并指出是哪一行 |
| 接口版本不符 | **拒绝加载**，说明期望值与你给的值 |
| id 撞名 | **报错**，建议用 `x-` 前缀 |

理由：本项目吃过"检查器悄悄失败却报绿"的亏（`doctor` 里就有一个真例子，已在 0.9.3 修掉）。**宁可吵，不可静默。**
